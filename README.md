# Artify AI

Plataforma para criar imagens publicitárias a partir de uma foto original, com aplicações Web (React) e Mobile (Flutter) e uma API compartilhada.

## Estrutura planejada

- `web/` — aplicação React + Vite.
- `mobile/` — aplicativo Flutter.
- `api/` — API compartilhada.

## Estado inicial

O projeto será desenvolvido incrementalmente. A geração real de imagens só será ativada após configurar um provedor compatível. Até lá, a API deve informar claramente que a geração não está configurada, sem produzir resultados fictícios.

## Segurança

Nunca coloque chaves de API no código React ou Flutter. Segredos devem permanecer no backend.
